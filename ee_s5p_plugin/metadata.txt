about=Browse all 1,100+ datasets in Google's Earth Engine Data Catalog without leaving QGIS and without copying dataset ids out of web pages. Search by id, title, publisher, tag or band name, then narrow by dataset type, provider, tags, date range and area of interest. The dataset list ships with the plugin, so browsing works offline, and can be refreshed from Google's published STAC catalog in a few seconds. For a chosen dataset the plugin shows bands with units and value ranges, availability and update cadence, licence and citation, and Google's own suggested colour palette. Extractions are estimated locally before being sent, so an over-large request is caught -- with a suggested resolution that would fit -- instead of failing after a long wait. Results are written as GeoJSON, CSV or JSON and loaded straight onto the map. Image collections, single images and feature collections are all supported. Requires the separate "Google Earth Engine" plugin, which provides the Earth Engine Python API and authentication; the catalog browser works without it.

changelog=1.0.0 (2026-10-01)
    Rewritten for modern QGIS.
    - Covers the entire Earth Engine Data Catalog (1,155 datasets) instead of a
      92-dataset subset, sourced from Google's published STAC catalog rather than
      by scraping HTML. No BeautifulSoup dependency.
    - Runs on Qt 6 as well as Qt 5, so it works on QGIS 4.x builds.
    - Catalog refresh, dataset reads and extractions run as background tasks:
      QGIS no longer freezes, and they can be cancelled.
    - Request size is estimated before sending, with a suggested resolution when
      a request would exceed the Earth Engine limit.
    - Dock is fully layout-managed and resizable; results are a sortable,
      searchable table.
    - Areas of interest are reprojected to WGS84, so selections on projected
      layers no longer land in the wrong place.
    - Fixed: CSV columns misaligned for rows with differing fields; pixel
      footprint polygons ~30% too small; hex colour palettes never recognised.
    - Full unit test suite and CI.

    0.1 (2020-12)
    Initial release: Sentinel-5P and selected collections, QGIS 3 / Qt 5.
